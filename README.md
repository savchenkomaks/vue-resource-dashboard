# 📊 Resource Dashboard

Дашборд загрузки команды: управление сотрудниками и их аллокацией на проектах.
Пет-проект на **Vue 3 + TypeScript**, демонстрирующий работу с данными, таблицами,
фильтрацией и формами — то, из чего состоят реальные корпоративные интерфейсы.

## Что внутри

- **Таблица сотрудников** с поиском (имя/роль), фильтрами по отделу и статусу,
  сортировкой по колонкам и визуализацией загрузки.
- **Статистика** (всего / на проектах / свободны / средняя загрузка) на `computed`.
- **CRUD**: добавление, редактирование и удаление сотрудника, детальная страница.
- **Форма с валидацией** — чистая функция-валидатор, отделённая от компонента.
- **Сохранение состояния** в `localStorage` (переживает перезагрузку).

## Стек и архитектурные решения

| Слой | Инструмент |
|------|------------|
| UI | Vue 3, `<script setup>`, Composition API |
| Типизация | TypeScript (strict) |
| Состояние | Pinia (setup-store) |
| Роутинг | Vue Router (ленивые маршруты) |
| Тесты | Vitest + @vue/test-utils |
| Сборка | Vite |

**Принципы:**

- Бизнес-логика вынесена в **composables** (`useEmployeeFilters`) и **чистые функции**
  (`validateEmployee`) — их удобно тестировать без монтирования компонентов.
- Компоненты «глупые», данные и логика живут в сторе и composables.
- Фильтры реализованы контролируемым компонентом через паттерн `v-model` (props + events).
- `<style scoped>` для изоляции стилей.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

## Скрипты

```bash
npm run dev         # дев-сервер
npm run build       # проверка типов + прод-сборка
npm run typecheck   # vue-tsc --noEmit
npm run test        # unit-тесты (Vitest)
```
